# 京都・幕末史跡マップ

幕末(1853〜1868)の京都・洛中の史跡を現代地図に重ね、時代順にたどれる単一ページです。ピンをタップすると由緒・検証・噂・出典を表示します。

- `index.html` … 地図ページ(Leaflet)
- `data.json` … 史跡(45件)、事件(10件)、補足カード(7件)
- `kyoto_bakumatsu_32s.mp4` … 時系列の32秒動画
